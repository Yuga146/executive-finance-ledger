# Executive Finance & Salary Ledger System Pro

An advanced, secure personal finance and salary ledger web application built with HTML5, Tailwind CSS, and Chart.js. Designed with a high-contrast dark interface, custom gold accents, and a 2x2 Domino card layout for managing multiple capital accounts (Bank, Cash, QR e-Wallet).

## Features
- **Secure Authentication:** PIN-protected login portal and admin mode.
- **Domino Capital Cards:** Clear 2x2 grid layout tracking Total Salary Credited, Bank Capital, Cash Capital, and QR e-Wallet balances.
- **Fast Expense Commitments:** One-tap presets for recurring financial commitments (loans, rent, bills, family expenses).
- **Salary Deduction Breakdown (%):** Real-time percentage analytics showing exact salary proportions consumed per expense.
- **Monthly Drill-Down Reports:** Comprehensive historical logs and savings percentage summaries.
- **100% Local Storage:** Client-side persistent data management.

## Deployment via GitHub Pages
1. Upload your self-contained `index.html` file to the root of your repository.
2. Go to your repository **Settings** -> **Pages**.
3. Set the build and deployment branch source to `main` (or `master`) and `/root`, then click Save.
